# Crime Data Mining & Machine Learning Project

## Overview

This project involved analyzing a large crime dataset to identify meaningful patterns and relationships using data mining and machine-learning techniques.

## Skills Demonstrated

* Python
* Data cleaning
* Exploratory data analysis
* Dimensionality reduction
* Machine learning
* Data mining
* Statistical analysis

## Project

The project involved working with more than 76 source files and preparing the data for analysis. My primary contributions focused on data cleaning and dimensionality reduction.

Dimensionality-reduction techniques included **PCA, LDA, and t-SNE**. The project also incorporated clustering techniques, including **K-means, Hierarchical Clustering, DBSCAN, and Gaussian Mixture Models**, to investigate patterns within the data.

## My Contribution

My primary responsibilities included preparing and cleaning the data and applying dimensionality-reduction techniques to make the dataset more suitable for further analysis and pattern identification.
