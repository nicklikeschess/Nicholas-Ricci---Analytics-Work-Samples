# Soccer Data Analytics Project

## Overview

This project involved analyzing soccer-related data to identify relationships, trends, and factors associated with player performance using statistical and data-analysis techniques.

## Skills Demonstrated

* Microsoft Excel
* Regression analysis
* Descriptive statistics
* Data analysis
* Pivot tables
* Advanced filtering
* Data visualization
* Statistical interpretation

## Project

The analysis used Excel to organize and evaluate soccer-related data. Statistical techniques, including linear regression and descriptive analysis, were used to examine relationships between variables and identify potential predictors of player performance.

The analysis found that **training hours** were the strongest predictor of player assets within the dataset.

## Key Analytical Methods

* Linear regression
* Descriptive statistics
* Pivot tables
* Advanced filtering
* Data visualization
* Interpretation of statistical relationships
