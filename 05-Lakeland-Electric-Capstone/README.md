# Lakeland Electric Pricing & Analytics Capstone

## Overview

This capstone project focused on analyzing electricity usage and pricing considerations to evaluate price sensitivity and develop data-driven recommendations.

## Skills Demonstrated

* Business analytics
* Price elasticity
* Pricing analysis
* Quantitative analysis
* Data interpretation
* Data-driven recommendations
* Financial and economic analysis

## Project

The project involved evaluating electricity usage and pricing using available weather and financial data. The analysis examined how changes in pricing could affect electricity demand and used quantitative methods to evaluate pricing considerations.

Because complete data was not available for every aspect of the analysis, the project focused on using reliable available information while clearly identifying limitations and assumptions.

## Key Analytical Focus

* Price elasticity
* Electricity usage patterns
* Pricing analysis
* Weather-related factors
* Quantitative evaluation
* Data-driven business recommendations
